# Swiggy Onboarding Audit

## Overview

Conducted a product onboarding audit of Swiggy’s first-time user experience to identify activation bottlenecks and friction before value delivery.

The project evaluates onboarding through:
- activation funnel analysis,
- user psychology,
- cognitive load,
- conversion optimization,
- and experimentation thinking.

---

# Core Insight

Swiggy delays value realization until users complete login, OTP verification, and location permissions.

This creates onboarding friction before users experience the product’s core value: restaurant discovery.

---

# Key Problems Identified

## 1. Login Before Value
Users are asked for personal information before seeing restaurants.

## 2. Permission Fatigue
Location permissions are requested before trust formation.

## 3. Checkout Complexity
Too many decisions are introduced during the highest-intent stage.

---

# PM Recommendations

### Browse Before Login
Allow restaurant browsing before OTP authentication.

### Pre-Permission Value Screen
Explain why location improves delivery relevance.

### Simplified First Checkout
Reduce first-order checkout friction using autofill and simplified payment flows.
